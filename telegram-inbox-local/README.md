# Telegram Inbox · 陪伴版（telegram-inbox-local）

社区插件 Telegram Inbox 的改版。原版做的事很简单：发给自己的 Telegram 机器人的消息，自动记进 Obsidian 今天的日记。

这一版往另一个方向走了一步：**让收件箱另一头不只是一个存档的地方，而是一个读过你日记的朋友。** 它看得到你今天在做什么、这几天熬到几点、手上压着哪些拖了很久的事，所以你说「好累」，它不会回一句空泛的「加油」；你说「搞定了」，它知道你搞定的是什么。

推荐度 ★★：只当收件箱用的话装上就能用；陪伴的部分要配合「任务提醒」「螺旋日程」两个插件和本机的 Claude 命令行（见文末「需要什么」）。

## 为什么做

手机上最顺手的输入框是聊天软件。想法、截图、链接、一句情绪，随手发给机器人，就进了日记，不用打开 Obsidian。

可日记记得越多，就越希望对面能回应一下。人在两种时候最想有人接一句：累到不想动的时候，和开心到想跟人分享的时候。这两种时候，打开一个 AI 聊天窗口、从头解释「我最近在忙什么」太累了；而你的日记里其实早就写着答案。所以干脆让机器人读你的日记，再回你。

## 两种模式：记录和对话

- **记录模式**（默认）：发什么记什么，和原版收件箱一样。
- **对话模式**：每句话它都会接着前面的话回你。对话内容不进日记：聊天归聊天，日记还是你自己写的那份。

怎么进、怎么出：

- **自己说**：发「对话模式」「进入对话模式」「陪我聊天」进入，会一直保持，直到你说「退出」「记录模式」「不聊了」，或者说「睡了」收工。
- **自动进入**：发情绪话（好累、好难受、好开心、想某个人……）、打招呼（哈喽、在吗）、以「聊聊」「陪我」开头，或者回复它的某条消息，都会自动进入对话模式。自动进入的，20 分钟没说话就自己回到记录模式，并告诉你一声（时长在设置里改）。
- **对话里也能记**：「?」「睡了」「小结」、`done` / `doing`、图片、带链接的消息照常处理；想把某一句记进日记，用「记 」开头。

## 你发什么，它做什么

下面是在记录模式里；在对话模式里，除了上面说的那几样，其余都是接着聊。


| 你发 | 它做 | 记进日记吗 |
|---|---|---|
| 任意文字、图片、链接、语音 | 记进今天的日记，时间按消息**发出**的时刻算，凌晨按日界算前一天 | 记 |
| `done 写稿 2h`、`doing 写稿` | 直接改今天日记里那条任务的状态，并补上时间 | 改那一行 |
| `哈喽` `在吗` `hi` | 马上打个招呼：按时间段说早安 / 晚上好 / 这么晚还在呀，带上你正在做的事和今天做完了几件；然后进入对话模式，等你往下说 | 不记 |
| `呱` `呱呱` `呱呱呱` | 呱回来，你呱几声它多呱一声 🐸，顺带说一句你今天在忙的事。「呱」是一个开心时的口头禅，换成你自己的，改 `chitchat()` 里的正则就行 | 不记 |
| `谢谢` `抱抱` `贴贴` | 回一句 | 不记 |
| `好累` `好难受` `好想她` `睡不着`…… | 进入对话模式。读你的**陪伴档案**和最近三天的日记，像朋友发消息那样回 4～8 行：先接住情绪，用日记里的具体事说明它懂你的处境，不说教 | 不记 |
| `好开心` `搞定了` `哈哈哈` `呱呱 简历过了` | 进入对话模式，跟你一起高兴：接住你做成的事，或者问你发生了什么好事，不趁机提醒你还有什么没做 | 不记 |
| 回复它的某条消息 | 进入对话模式，接着那条聊 | 不记 |
| `?` | 一张图文版的今日螺旋日程：⭐ 正在做、接下来、排不下的、今天过了多少 | 不记 |
| `睡了` `休息了` `不干了` | 收工：把今天的结束时间定在这一刻，进行中的任务退回待办；然后发一条今天的小结：做成了什么、明天先做哪件，再说几句话让你安心去睡 | 记一行时间 |
| `起了` `早安` | 把今天的开始时间定在这一刻，回一条今天的容量 | 记一行时间 |
| `小结` | 只要今天的小结，不收工 | 不记 |

哈喽、呱、谢谢是本地即时回复，不调用模型，发出去一秒内就回。

对话、小结要读日记、调 Claude，大约 8～30 秒。这段时间它不会让你干等：马上先回一条「💭 收到，在想……」，每隔几秒换一句进度（「📖 翻了翻你最近的日记……」「✍️ 在组织语言……」），写好后这条提示消失，正式回复作为新消息发来。用新消息而不是改原消息，是为了你切出聊天后手机也会响。

## 它也会主动找你

配合「任务提醒」（nautilus-notify）插件，这些消息会按时发到同一个机器人：

- 🌀 每天几个固定时刻（默认 12:00、18:00、22:00）发一次图文版螺旋日程
- 🏋️ 早上的健身早报：今天练什么、这周练了几天、是不是称重日
- 🐢 每晚列出拖了好几天的待办，每件带「🗑 不做了 / 📅 挪明天 / 💤 搁置」三个按钮，点一下就改好日记
- 🃏 Anki 里有到期卡片时提醒复习
- 🧭 周日读一遍这周的日记，写一份「这周做了什么」：主要做了哪几类事、推进最大的、拖着没动的、下周先做什么
- 🔔 人不在电脑前（一段时间没动键盘鼠标，或者锁屏了）时，本来弹在电脑上的提醒同时发到 Telegram

## 陪伴档案：教它怎么陪你

情绪话、小结、周洞察都会先读库里的一页笔记（默认 `健康/陪伴档案.md`，在「任务提醒」设置里可以改路径）。这页写给它看，它照着回你。想改它说话的方式，就改这页，下一条消息就生效。

建议写这几块：

```markdown
- 我是谁
	- 做什么工作、最近在忙什么、作息
	- 在乎的人，和他们的情况（比如异地、在上学）
- 我累的时候通常是因为什么
	- 最好引用自己日记里的原话，比如「不怕苦，怕混乱」
- 回我的时候
	- 先接住情绪，再谈别的；不要一上来给方案
	- 不要哄、不要鸡汤；肯定我的时候用日记里的具体事实
	- 建议最多一个，而且要小；我没问可以不给
	- 短一点，像朋友发消息
- 我开心的时候
	- 我的口头禅，听到就怎么回
	- 跟着高兴就好，别借机提醒没做完的事
- 如果我说了想伤害自己的话
	- 只有这一次真的说了才用这条
	- 先陪着，再请我联系身边的人或心理援助热线
```

几条写死在代码里的原则，不管档案怎么写都会遵守：

- 只回应你自己的感受。日记里别人说的话、你摘抄转述的内容，不会被拿来套在你身上，也不会提别人的隐私。
- 只有你这一次明确说出想伤害自己、不想活，才会认真接住并给出求助热线；日记里出现过相关的词，不会让它主动提起。
- 模型调用失败时，回一句简短的陪伴话，不会让你等了半天没有回应。

它不是心理咨询，也替代不了身边的人。它能做的，是在你随手发出一句话的时候，有一个看过你日记的声音接住你。

## 需要什么

- **一个自己的 Telegram 机器人**：找 @BotFather 建一个，把 token 填进设置，白名单里写你的 Telegram 用户名。私聊发过一条消息后，它会记下你的 chat id，「任务提醒」主动发消息时要用。
- **收件箱、`done` / `doing`**：只要这个插件。
- **`?`、收工、起床、小结**：要「螺旋日程」（nautilus-spiral），日记用 Logseq 式的 `TODO` / `DOING` / `DONE` 写任务。
- **打招呼、呱、陪聊、主动推送、按钮**：要「任务提醒」（nautilus-notify）。
- **陪聊、小结、周洞察**：要本机装好并登录 [Claude Code](https://claude.com/claude-code) 命令行（`claude`）。这几项会把日记摘要发给 Claude 生成回复，用的是你自己命令行的登录。
- **桌面端的 Obsidian 要开着**。电脑睡着时机器人回不了，醒来后会补上；「任务提醒」可以在插电时阻止 Mac 闲置睡眠（屏幕照样息屏）。手机上的 Obsidian 也装了这个插件的话，手机开着时可能先把消息收走，而陪聊只在桌面端有。
