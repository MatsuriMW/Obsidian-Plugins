# Hover Outline（悬浮目录）

插件 ID：`hover-outline`

仿 Claude Code 对话框左上角的隐藏式目录。平时只在编辑区左上角露出一列短横线，不占地方；鼠标移上去才展开成完整目录。用来替代 Quiet Outline 那种常驻侧栏的大纲。

## 怎么用

- **收起时**：一条短横线 = 一个目录项，越短层级越深；当前位置那条颜色深一些。
- **展开**：鼠标移到短横线上，展开成一张目录卡片。当前位置那一栏是黑字，其余淡显。
- **跳转**：点某一栏，那一行停在视口**正中**，并**选中**这一行的文字（编辑模式选行内文字，不含列表符号、`#` 和行尾 `^块ID`；阅读模式用浏览器选区选中）。上方内容不够时停在能滚到的最近位置。
- **刚点的那一栏**：前面的 handle 变长一点，整栏往外突出；点别的栏、或者自己滚动了，就恢复原样。
- **什么时候收起**：点完不收，鼠标离开触发区域才收。
- **手机**：没有 hover，点一下短横线展开，点外面收起，点某一栏跳转后收起。

## 目录里有什么

- **开头 + 标题 + 结尾**：开头回到最上面，结尾滚到最底。
- **默认显示到 h3**。整篇最高只有 h4 这类的，至少显示最高那一级。
- **层级切换**：笔记里有比默认层级更深的标题（h4 及以下）时，卡片顶上出现 H1…Hn，只列这篇用到的层级。切过的层级在这次打开 Obsidian 期间按文件记住。
- **每项最多显示 7 个字**，多的用「…」，鼠标悬停看全文。链接、加粗等标记会去掉，只留看得见的字。

## 日记

`日记/` 文件夹里的笔记，或 frontmatter 里有 `journal` 的，按顶格分割线（`- ---` 或单独一行 `---`）分段，每段算一个 h1。分区规则和 Done To Top 的「一键整理」一致：

| 段 | 目录里显示 |
|---|---|
| 第一段（第一条分割线之前） | DONE |
| 紧接着的、任务全是 DOING / NOW / PAUSED 的段 | DOING |
| 再紧接着的、任务全是 TODO / LATER / WAITING / SUSPENDED 的段 | TODO |
| 其余段 | 分割线下第一条（去掉状态词、时间和行尾的 `← [[来源]]`） |

点日记的分段，跳到分割线下的第一条并选中它。日记里如果也写了标题，标题整体降一级挂在分段下面。

## 不显示的情况

- 正文里有 ` ```dataview ` 或 ` ```dataviewjs ` 代码块的笔记（看板、菜谱台这类）。
- 除了开头和结尾没有别的目录项的笔记。

## 当前位置怎么算

- 平时按**视口正中**那一行所在的节算（跳转是把目标放到正中的，两边一致）。
- 刚点过的那一栏，在你自己滚动之前一直算当前（文首文末对不了中时，不会算到隔壁去）。
- 在最上面算「开头」，滚到底算「结尾」。

## 外观

- 卡片背景用 `--ho-card-bg`，没设就用 `--background-primary`。库里的 CSS 片段 `claude-background` 把它设成了纯白，和 Claude 的弹出卡片一样。
- 编辑模式、阅读模式都能用；编辑时目录实时更新。

## 和其它插件的关系

- 「居中并选中」的跳转代码（`revealLine`）和第二大脑、Backlinks and Export 里的是同一份，改的时候三处一起改。
- 装了这个之后 Quiet Outline 已经关掉（文件还在，想恢复去第三方插件里打开）。
