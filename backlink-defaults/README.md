# Backlinks and Export（反链与导出增强）

插件 ID：`backlink-defaults`（改名前叫 Backlink Defaults，ID 没改，免得丢设置）

## 目标

1. **反链面板做到和 Logseq / Roam Research 一样好用**：反链不是一行行孤立的摘录，而是带着上下文的「块」。看得到它在原文里的位置，能就地展开上下文、就地编辑，不用跳走。
2. **导出比 Logseq 更好**：导出 PDF 时可以把「链接到当前文件」的内容一起带上，排版也能调。一篇概念页导出来，就是这个概念在整个库里的全部讨论。

只在运行时改 Obsidian 自带的反链面板和导出对话框，不改 Obsidian 的文件。关掉插件就恢复原样。

## 反链面板

### 像 Roam / Logseq 那样看块

- **以块为单位**：命中的列表项连同全部子块一起显示；命中的是标题时，显示这个标题下的整节。母块里已经显示过的引用，子块里不再重复列一条。
- **面包屑**：命中块上方一行灰字，列出它所在的完整路径（所属标题 › 各级母块）。和上一条路径相同时不再重复显示，接在上一条下面。
- **点面包屑逐级展开上下文**：
  - **直接点**某一级母块：就地展开到这一级，把它下面和命中块并列的兄弟块一起显示出来。展开后面包屑少一级，再点新的最后一级就继续往外展开，可以一直点到最外层；点标题那一级会展开整节。行尾「收起」回到原样。
  - **⌘ 点**：跳到原文那一行。
  - **Shift 点**：在右侧栏打开。
- **按 Markdown 渲染**：列表、加粗、链接、复选框都正常显示，不是源码。链接可以点、悬停可以预览，复选框可以直接勾（写回原文）。子块太长时先折叠，点「展开其余 N 行」看全部。
- **就地编辑**：点块里任意位置就地编辑这一块的源码，写回原笔记。⌘↩ / ⌘S 保存，Esc 取消；⌘B / ⌘I / ⌘E / ⌘⇧H 加粗、斜体、行内代码、高亮；Tab / ⇧Tab 调缩进；选中文字后输入成对符号会包裹选中的文字，不会替换掉。点框外没改过就取消，改过就自动保存。右上角 ↗ 或 ⌘ 点跳到原文。
- **Shift 点 = 右侧栏叠放**：反链里的链接、块、面包屑、文件标题，Shift 点都在右侧栏往下叠放一页，几页可以并排对照。列表块会用 Bullet 插件的 Zoom 聚焦进去。
- **块引用计数**：命中块带 `^id` 时，右下角显示它被引用几次，点开看谁在引用。

### 排序和分组

- **页面在前**，按关系紧密度排：互相链接 > 属性里写了指向当前页的链接 > 正文提到次数。
- **日记在后**，按日期从新到旧：最近 12 个月按月分段，更早的按年折叠，点年份展开。
- **共现筛选**：列出这些引用里还一起出现了哪些页面，按关联紧密度排。点 = 只看含它的，Shift 点 = 排除它。
- **分组**：按最紧密的几个共现页把反链聚成可折叠的簇，一屏扫完主题交叉。
- **名字筛选**：当前页有别名时，列出「文件名 + 各个别名」，可以只看用某个名字的引用，或者排除某个名字。
- **文字筛选**：正文底部那份反链也加了筛选框（侧栏面板自带搜索框）。
- `Wiki/` 里 AI 维护的页面不进反链列表，单独列成「📘 Wiki」入口。

### 未链接提及

- 默认折叠。
- 点「转为链接」后面板不刷新、不重排，按钮变成「已链接 ✓」，阅读位置和思路不被打断。同一篇里可以连续转多处；离开这一页再回来时重新读取。
- 可以按笔记设置区分大小写：在属性里写 `大小写敏感: true`（也认 `case-sensitive`），只显示和文件名 / 别名一字不差的提及。命令「切换：『提到当前文件名』区分大小写」直接写进当前笔记属性。

## 导出 PDF

接管 Obsidian 自带的「导出为 PDF」对话框，多出两组选项：

- **包含反链（链接到当前文件）**：正文后面接上引用这一页的全部内容，按来源笔记分组，顺序和反链面板一样。每一条都是整块：列表项连子项、标题连整节、段落连整段，上方带面包屑路径；通过属性链接过来的写一句说明。`Wiki/` 不导出。
- **排版**：精致排版开关、正文字体、标题字体（只列出本机装了的）、字号三档、强调色。样式只加在导出窗口里，不改笔记和主题。

Logseq 导出只能导出当前页本身，带不上反链；这里一篇概念页能连同所有提到它的地方一起导出成一份排好版的 PDF。

## 命令

- **跳到当前笔记的反向链接**（默认没有快捷键，库里设成了 ⌘⌥B）：滚到正文底部的反链并聚焦筛选框；没有就唤出侧栏反链面板。
- **切换：「提到当前文件名」区分大小写（写进当前笔记属性）**

各项功能都能在 `main.js` 开头的常量里单独开关。
