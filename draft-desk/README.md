# 稿件台（draft-desk）

写稿时按写作步骤调用工具。装在稿子库「Obsidian Vault」，挂在第二大脑的写作模式面板上：进写作模式，面板顶上「🤖 Claudian」「🧰 文本工具」后面就是四个下拉按钮。每个操作也都注册成了命令（「稿件台：填坑」等），不进写作模式也能用，可以绑快捷键。

**作用范围**：选中了就只处理选中部分，没选中就处理整篇（属性区不动）。

| 按钮 | 操作 | 怎么跑 | 结果 |
|---|---|---|---|
| ① 脉络 | grill-me 压测稿子 | Claudian 新开对话 | 结论写成 `稿件压测-修改建议.md`，不动稿子 |
| | 方向发散 | 后台 `claude -p` | 弹窗显示 3–5 个写法方向，同时追加进 `方向发散.md` |
| ② 落实 | 填坑 | 后台 `claude -p`（联网 + 读主库） | 每个 `【坑：……】` 下面插一个折叠的 `[!补料]` 标注，带来源链接 |
| | 概念锚点检索 | 扫主库 → Claudian | 材料包 `概念-<名称>.md`（概念页 + 点名提到它的段落 + 意思相近的段落），在 Claudian 里结合稿子讨论 |
| | QWS 追问补料 | Claudian（qws skill） | `稿件追问-补充素材.md`，不动稿子 |
| ④ 扩写 | 扩写 / 补充 · 正式化 · 文白交杂 | 后台 `claude -p` | 选中：预览后替换 / 插在下面；整篇：另存 `<稿名> v2.md` |
| ⑤ 修整 | 一键规范排版 | My Text Tools 快捷指令「稿件台 · 规范排版」 | 直接改稿子，⌘Z 一步撤回 |
| | 列表块连成段落 | 后台 `claude -p` | 同 ④ |

- 素材类产出（压测、发散、概念、追问）都放主库 `选题/_采访/<选题名>/`。选题名取稿子属性 `选题`，没有就找主库选题页里 `稿件:` 写着这篇的，再没有就用稿名。
- 改写用的风格提示词每次从主库 `写作与创作/` 现读：扩写和连成段落按稿子属性 `形式` 选（口播 → 口播稿风格，博客 / 长文 → 书面语风格，其他 → 文稿风格）；正式化用书面语风格；文白交杂用书面语风格 + 文白交杂风格提示词。
- 改写只改正文句子：标题、`>` 标注、表格、`【★】`、`【坑】` 原样保留；改完数量对不上会提醒。
- 后台任务在状态栏显示「稿件台：正在…」。同一个操作再点一次 = 取消，点状态栏也能取消。
- 私密：第二大脑设置里的「私密链接」（比如「宝」），同名文件夹和提到 `[[它]]` 的内容不进补料和材料包。
- 填坑和概念检索会借第二大脑的语义检索（本机 Ollama + embeddinggemma）在主库里按意思找；Ollama 没开就只按字面找。

**依赖**：第二大脑（写作模式面板、主库路径、语义检索）、My Text Tools（规范排版）、Claudian（对话类）、本机 `~/.local/bin/claude`（后台类）。缺哪个，只影响用到它的那几项。

设计和决策记录见 [DESIGN.md](DESIGN.md)。
